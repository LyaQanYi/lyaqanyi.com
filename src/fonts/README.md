# 标题字体

`source-han-sans-cn.woff2` 由用户提供的 `Source Han Sans CN.ttf` 转换而来，保留完整字形，未做字符裁剪。

显示名称沿用用户提供的文件名；文件的内嵌字体族名仍为 `cmdysj`，Regular / 400。

- 原始文件：8,470,944 字节。
- 网页文件：3,861,616 字节。
- 字符映射：30,786，保留完整字形。

共享加载配置在 `src/lib/fonts.ts`。全站通过 `--f-display` 使用该字体，正文和导航沿用 `--f-sans`，辅助信息沿用 `--f-mono`。

原版 Instrument Serif 仅在 `/font-preview` 对比页加载。
